# Franchise Hockey Tycoon

> **🚧 In development.** This is an early, unfinished build. Expect bugs, balance changes and wiped saves between updates. Features, numbers and names may change at any time.

A mobile hockey management clicker. Build the team, train your players, draft prospects and climb from the Rec League to the Elite division. The season runs itself; you run the franchise.

## Play

**https://brysonluke18.github.io/Franchise-Hockey-Tycoon/**

- **iPhone:** open the link in Safari, tap Share, then **Add to Home Screen**.
- **Android:** open it in Chrome, tap the ⋮ menu, then **Install app**.

It runs full screen, works offline after the first visit, and keeps your save on that device. Purchases and ads in this build are placeholders: nothing is ever charged.

## For the developer

- `breakaway/` — the game (plain HTML, CSS and JavaScript, no build step).
- `docs/` — the installable web app GitHub Pages serves. Generated by `build-web.ps1`; do not edit by hand.
- `tools/bot.js` — dev-only playtest bot. Load it in the browser console on a local copy and call `runBot({ seasons: 10 })`.

To ship an update: bump `CACHE` in `breakaway/sw.js`, run `./build-web.ps1`, then commit and push.
